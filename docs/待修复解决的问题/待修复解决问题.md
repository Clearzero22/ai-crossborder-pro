根据对整个项目业务逻辑代码的深入分析，以下是按严重程度分类的详细问题报告：
业务逻辑代码问题分析报告
一、严重问题（CRITICAL — 会导致运行时崩溃或数据错误）

1. placeholderImagePath 未定义导致 AI 优化功能崩溃

- 文件: packages/frontend/src/plugins/index.ts:465,504,531
- 问题: 变量 placeholderImagePath 被注释掉了，但 Gemini/ChatGPT 纯文本模式下仍然引用它，会抛出 ReferenceError。整个 AI 优化核心流程无法工作。

2. 状态属性拼写错误 activeTab126

- 文件: packages/frontend/src/hooks/useWorkflowState.ts:491
- 问题: 测试单个节点时，面板不会切换到日志 tab，应为 activeTab: "logs" 而不是 activeTab126: "logs"。

3. 引擎节点出错后步骤索引错乱

- 文件: packages/frontend/src/engine/WorkflowEngine.ts:153-201
- 问题: 节点出错时 onNodeOutput 不会被调用，但 stepIndexRef.current++ 只在 onNodeOutput 内递增。后续成功节点的 step_index 会错位，数据库记录全部混乱。

4. 获取运行数据时返回了错误的产品

- 文件: packages/backend/src/services/crawler-service.ts:176 及 api-server.ts:240
- 问题: getRunData 中 db.getProducts(undefined, 1) 没有按 runId 过滤，查询任何 run 都会返回最近一个产品，而非该 run 对应的产品。

5. AI 优化 JSON 解析回退字段名错误

- 文件: packages/backend/src/api-server.ts:863-881
- 问题: 正则 /\{[\s\S]\*\}/ 贪婪匹配会捕获过多内容。当解析失败时，回退对象用了 optimizedDescription，但正常解析成功的字段是 optimizedLongDescription，导致正常解析时该字段总是 undefined。

6. AI Provider 测试端点参数传错了

- 文件: packages/backend/src/api-server.ts:1377
- 问题: provider.recognize(testImage, { prompt: 'test' }) 应该传一个对象参数 provider.recognize({ image: testImage, prompt: 'test' })。测试端点永远失败，但 catch 块却返回成功，给用户假阳性结果。
  二、高危问题（HIGH — 数据丢失、逻辑错误、功能失效）

7. 测试节点不清理之前的状态

- 文件: packages/frontend/src/hooks/useWorkflowState.ts:480-578
- 问题: testNode() 不会清除 stepOutputs、executionLogs、nodeStatuses，测试结果会和上一次完整执行的结果混在一起。同时 executionIdRef、stepIndexRef、stepTimingsRef 也不会重置，测试数据可能写入错误的执行记录。

8. 测试节点总是给空输入

- 文件: packages/frontend/src/engine/WorkflowEngine.ts:155-156
- 问题: testNode 从指定节点开始执行，但 DataBus 已清空，第一个节点 previousOutput 为 undefined。依赖上游数据的节点（如 AI 优化）单独测试时必然失败。

9. 失败的步骤从不持久化到数据库

- 文件: packages/frontend/src/hooks/useWorkflowState.ts:384-394
- 问题: onNodeOutput 只在成功时调用，总是记录 status: "success"。失败步骤的记录完全丢失，无法从数据库调试工作流失败。

10. onComplete 即使有错误也标记为"完成"

- 文件: packages/frontend/src/engine/WorkflowEngine.ts:204-206
- 问题: 引擎在节点出错后继续执行，最终 onComplete 总是被调用，执行记录状态为 "completed"。无法区分完全成功和部分失败的工作流。

11. PlanGuard 在没有 fallback 时不拦截

- 文件: packages/frontend/src/components/PlanGuard.tsx:12-21
- 问题: 当 result.allowed 为 false 但没有传 fallback 时，children 依然渲染。订阅限制形同虚设。

12. checkFeatureLimit 功能检查逻辑永远失败

- 文件: packages/frontend/src/utils/planGuard.ts:25-34
- 问题: 免费计划的 features 数组是 ['basic']，但 feature 名是 'workflow-execution'，_includes 检查永远不通过。_ 只有 plan 为 null 时才放行（API 未加载时反而允许所有功能）。

13. startExecution 读取过期的 activeTemplateId

- 文件: packages/frontend/src/hooks/useWorkflowState.ts:346,466
- 问题: state.activeTemplateId 不在 useCallback 依赖数组中，切换模板后下一次执行仍使用旧模板 ID 持久化。

14. ChatGPT 保存文件路径时间戳不匹配

- 文件: packages/backend/src/services/chatgpt-file-service.ts:289-297
- 问题: savePath 用了 Date.now()，savedPath 又用了一次新的 Date.now()，返回给前端的路径和实际保存的文件名不一致。

15. 工作流日志批量插入没有事务

- 文件: packages/backend/src/core/database-service.ts:367-381
- 问题: insertWorkflowLogs 逐条插入无事务，中间失败会导致部分日志丢失，但返回值仍声称全部成功。
  三、中等问题（MEDIUM — 功能缺陷、数据不准确）

16. rawKeywords Schema 类型与实际数据不匹配

- 文件: packages/frontend/src/plugins/index.ts:151-152 vs 1606
- 问题: Schema 声明为 type: "string"，但实际数据是对象数组。可能导致序列化或 UI 显示错误。

17. AI 竞品分析解析逻辑脆弱

- 文件: packages/frontend/src/plugins/index.ts:616-619
- 问题: 用 lastIndexOf("###") 提取竞品分析，如果 AI 输出格式稍有变化就会提取到错误内容。

18. Claude Provider 不支持 system message

- 文件: packages/backend/src/ai-providers/providers/claude.provider.ts:99-115
- 问题: Anthropic API 要求 system 消息作为顶层参数，不能放在 messages 数组中。当前代码会把 role: 'system' 当普通消息发送，会导致 API 400 错误。

19. Gemini Provider 把 system 消息静默转为 user

- 文件: packages/backend/src/ai-providers/providers/gemini.provider.ts:99-119
- 问题: role: 'system' 被映射为 role: 'user'，系统指令失去特殊语义，AI 行为可能不符合预期。

20. /api/ai/optimize 硬编码为 Gemini 浏览器自动化

- 文件: packages/backend/src/api-server.ts:853
- 问题: 没有使用多 Provider 回退架构（aiRouter），必须依赖 Gemini 网页端登录，无头模式下可能失败。

21. HTTP 请求插件 redirect 配置无效

- 文件: packages/frontend/src/plugins/index.ts:1708
- 问题: followRedirect ? "manual" : "manual" 两个分支都返回 "manual"，用户配置被完全忽略。

22. HTTP 请求超时在工作流中无效

- 文件: packages/frontend/src/plugins/index.ts:1720-1728
- 问题: 当 ctx.abortSignal 存在时（工作流执行中总是存在），自定义超时 AbortController 永远不会被使用。

23. openShopifyPlugin 标签写成了 "打开 Amazon 后台"

- 文件: packages/frontend/src/plugins/index.ts:743

24. AllDataTable N+1 请求模式

- 文件: packages/frontend/src/pages/DashboardPage/AllDataTable.tsx:148-185
- 问题: 先获取所有执行列表，再对每个执行单独请求详情，100 条数据会触发 101 个 HTTP 请求。

25. 订阅计划为 null 时允许所有功能

- 文件: packages/frontend/src/utils/planGuard.ts:11-13
- 问题: API 未加载或网络错误时，所有付费功能都开放访问。

26. Gemini 安全过滤返回空字符串无提示

- 文件: packages/backend/src/ai-providers/providers/gemini.provider.ts:137-139
- 问题: finishReason: "SAFETY" 时返回空字符串，调用者无法区分正常空响应和安全拦截。

27. AI Provider 回退数量限制不合理
