## ⚙️ 配置选项详解

### 选项 1：ASIN (手动输入)

**类型**：文本框
**默认值**：空
**说明**：
- 留空：从上游节点获取 ASIN
- 填写：使用指定的 ASIN（优先级高于上游）
- 格式：10 位字母数字，如 `B08F5M1K9M`

**示例**：
```
输入：B08F5M1K9M
结果：抓取该 ASIN 的关键词
```

### 选项 2：无头模式

**类型**：复选框
**默认值**：勾选 (true)
**说明**：
- ✅ 勾选：浏览器在后台运行，不显示窗口
- ❌ 不勾选：显示浏览器窗口（调试用）

**建议**：
- 生产环境：勾选
- 调试阶段：不勾选，观察爬虫运行过程

### 选项 3：最大关键词数

**类型**：数字框
**默认值**：50
**范围**：1-1000
**说明**：限制返回的关键词数量

**示例**：
```
输入：10
结果：只返回前 10 个关键词
```

## 🚨 常见错误处理

### 错误 1：未提供 ASIN

**提示**：
```
❌ 未提供 ASIN：请在节点配置中填写，或连接上游 Amazon 商品详情节点
```

**解决方案**：
- 方案 A：在节点配置中手动填写 ASIN
- 方案 B：连接「Amazon 商品详情」节点到上游

### 错误 2：API 请求失败

**提示**：
```
❌ HTTP 500
```

**解决方案**：
1. 检查后端服务器是否运行：`lsof -i :3001`
2. 启动后端服务器：`cd backend && bun run dev`
3. 检查网络连接

### 错误 3：ASIN 格式错误

**提示**：
```
❌ Invalid ASIN format. ASIN must be 10 alphanumeric characters.
```

**解决方案**：
- 确保 ASIN 是 10 位字母数字
- 示例：`B08F5M1K9M` ✅
- 错误：`B08F5M1K9` ❌ (只有 9 位)

## 💡 使用技巧

### 技巧 1：批量处理

要处理多个 ASIN，可以：

1. 使用「Amazon 竞品搜索」获取多个 ASIN
2. 创建多个西柚找词节点实例
3. 每个实例处理一个 ASIN

### 技巧 2：数据组合

将西柚找词与其他节点组合：

```
[Amazon 商品详情] → [西柚找词] → [AI 优化文案]
                                        ↓
                                  [Shopify 发布]
```

使用抓取的关键词生成 SEO 优化的商品文案。

### 技巧 3：调试模式

遇到问题时：

1. 关闭「无头模式」
2. 观察浏览器自动操作过程
3. 检查西柚找词网站是否正常
