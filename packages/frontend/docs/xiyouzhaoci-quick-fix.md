# 西柚找词节点 - 快速修复指南

## 问题

```
❌ 失败: 未提供 ASIN：请在节点配置中填写，或连接上游 Amazon 商品详情节点
```

## 原因

节点没有收到 ASIN 数据，有两种可能：
1. 节点配置中未填写 ASIN
2. 没有连接上游提供 ASIN 的节点

## 解决方案

### 方案 1：手动配置 ASIN（快速测试）

#### 步骤：

1. **点击**「西柚找词 - 关键词挖掘」节点

2. **在右侧配置面板**找到「ASIN (手动输入)」字段

3. **填入测试 ASIN**：
   ```
   B08F5M1K9M
   ```

4. **配置其他选项**（可选）：
   - ☑ 无头模式：保持勾选
   - 最大关键词数：保持 50

5. **点击「运行」按钮**

#### 可视化：

### 方案 2：连接上游节点（完整流程）

#### 步骤：

1. **添加 Amazon 商品详情节点**
   - 从左侧面板拖拽「Amazon 商品详情」到画布

2. **配置 Amazon 商品详情节点**
   - 点击该节点
   - 在右侧配置中填写 ASIN：`B08F5M1K9M`
   - ☑ 无头模式：勾选
   - ☑ 保存到数据库：勾选

3. **连接两个节点**
   - 从「Amazon 商品详情」节点的右侧连接点
   - 拖拽到「西柚找词」节点的左侧连接点

4. **添加开始和结束节点**
   - 添加「开始」节点，连接到 Amazon 商品详情
   - 添加「结束」节点，从西柚找词连接

5. **运行工作流**

## 常见错误排查

### 错误 1：仍然提示"未提供 ASIN"

**原因**：节点配置中 ASIN 字段为空字符串

**解决**：
- 删除配置字段中的空格
- 重新输入完整的 ASIN（如：`B08F5M1K9M`）

### 错误 2：后端服务器未启动

**原因**：backend 服务未运行

**解决**：
```bash
cd backend
bun run dev
```

### 错误 3：节点连接后仍报错

**原因**：上游节点未正确输出 ASIN

**解决**：
1. 先单独运行上游节点（如 Amazon 商品详情）
2. 检查其输出是否包含 `asin` 字段
3. 确认连接线正确连接

## 需要帮助？

如果按照上述步骤操作后仍然有问题，请检查：

1. **浏览器控制台**（F12）是否有错误信息
2. **后端终端**是否有错误日志
3. **节点配置**是否正确保存

常见的配置问题：
- ASIN 字段填写了空格
- 上游节点没有正确执行
- 工作流没有正确保存
